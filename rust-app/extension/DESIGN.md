# 扩展界面约定

继承 `../DESIGN.md` 的视频优先原则与 `../public/style.css` 的现有深色设计，不引入新框架或装饰。

- 配色：canvas #101112，surface #202223，ink #eef0ed，muted #adb4ae，border #3c433e，accent #8fcab0，hover #afddc7，onaccent #14291c，error #ffaaa5。
- 字体：系统 sans-serif；正文 16px，辅助信息 14px，标题 20px。视频字幕中文 16–26px、英文 14–22px，随视口变化。
- 间距：4/8/12/16/24px，圆角 6px，所有控件最小高度 40px。Chrome 弹窗固定宽 360px。
- 组件：带标签的密码输入、原生选择框、主按钮、停止按钮、状态文本。支持默认、hover、focus-visible、disabled、error。主按钮在捕获期间禁用，停止按钮在未捕获时禁用。
- 字幕：英文在上、中文在下，透明度 .82 的黑底白字，播放器底部14%，两侧5%，不拦截视频操作。英文稳定片段先显示，中文独立跟译；新增英文清空旧中文，版本校验抑制过期中文；12秒无更新自动清除。
- 可访问性：显式 label、原生键盘控件、2px焦点轮廓、aria-live状态。无需动画。
- 验收限制：普通网页预览只能检验排版；真实 Chrome 扩展权限、捕获、原声及全屏必须单独联调，不以单元测试代替。

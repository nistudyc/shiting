# 视听界面约定
视频优先，设置和字幕记录保留右侧抽屉。默认深色，设置旁增加 40px 可点击日/月图标切换深浅色；设置中仍能选择跟随系统。设置面板默认 10% 透明度，可调 0–80%；只改变背景，不改变文字透明度。字幕背景透明度独立控制。用户播放成功后自动准备模型并开启字幕；手动关闭后缓冲和恢复不会擅自重开，换源后恢复默认自动开启。

## 现有界面延续
保留 public/style.css 中的既有 token，不重新设计播放器。深色 canvas #101112、surface #202223、ink #eef0ed、muted #adb4ae、accent #8fcab0；浅色延续原值。系统字体，正文16px、辅助14px、标题24px；4px间距单位、6px圆角、40px按钮。设置抽屉宽480px，手机占满宽度。新增 Chrome 配对区使用现有 setting-section、label、input、button，与翻译设置同层级；状态沿用 role=status。配对码只在设置中呈现。

## 可复用控件与状态
按钮：默认、悬停、按下、键盘焦点、禁用；输入框：默认、焦点、只读配对码。错误使用现有 error 色与文字，不能只靠颜色。减少动画设置保留。扩展复用相同配色、字体、间距和按钮状态，字幕覆盖层不截获播放器鼠标操作。

频道选择：沿用原生 select 控件，位于顶栏、主题切换左侧，桌面最长240px，小屏140px。选中后直接播放，标题显示频道名，不增加单独频道页。列表采用用户指定 Gist 的当前快照，按地址去重；不自动播放。

实时字幕状态：第一轮识别立即显示，后续结果允许校正；中文从第一轮结果开始翻译，更新间隔1秒。原生WebKit通过HLS音轨片段解码并按播放时间采样，避免Web Audio媒体元素采集全零；错误必须显示并停止字幕。DASH频道在列表中标明暂不支持并禁用。
原生App全屏使用窗口全屏API，stage沿用现有全屏尺寸和退出按钮，Escape退出；浏览器保留HTML全屏。只向本机播放器页授予窗口全屏读写权限。

## 原生 Liquid Glass 改版（用户新增要求，基线已归档）

- 原生外壳：SwiftUI/AppKit标准控件与系统Liquid Glass；WKWebView只承载已验收的视频和字幕，不承载菜单、设置或操作按钮。Rust以应用内子进程提供既有本机服务。最低macOS26，当前macOS27/SDK27实测。
- 原生布局：视频全窗口；顶部操作区约44px，留出系统交通灯；底部操作区36–40px，一行状态与播放/字幕/全屏；消除旧底部两行112px占用。
- 原生字体：系统SF，控件13–14pt，辅助11–12pt，欢迎标题24pt；系统语义色，避免网页式色块。
- 真实材料：按钮使用系统glass/glassProminent样式，相邻玻璃控件置于GlassEffectContainer；popover/sheet/menu全部SwiftUI原生。玻璃仅用于交互层，视频和字幕维持现有已验收外观。
- 开始观看：原生输入框可直接粘贴地址；同屏提供浏览频道。设置中复用频道列表与地址输入。
- 频道选择：搜索、当前选中状态，DASH项明确不可选；选择立即播放。所有控制沿用既有服务/音轨/推理逻辑。
- 设置：原生字幕模式、字幕底色透明度、外观、翻译服务与安全密钥输入、字幕历史。系统材料由macOS响应透明度/辅助功能，不能用CSS冒充。
- 动作：原生菜单、键盘焦点、popover关闭、Escape/窗口全屏；清晰提示载入错误。所有本机桥接参数均JSON编码，只允许固定动作。
- 保留基线：dist/Shiting-Rust-macOS-arm64-20260919-accepted.zip 和对应源码tar.gz。新外壳输出独立dist/视听.app及新ZIP。

## 可选缓冲、闲置控制与字幕回看

- 保留当前默认播放，设置新增默认关闭的字幕缓冲与 3／4／5 秒选择；本机偏好持久化，更改仅下次载入生效。
- 底部36pt控制层在播放且连续3秒无操作时，以0.18秒透明度转换为宽64pt、高6pt的玻璃提示条；保持原布局占位，不改变视频及字幕尺寸。提示条仍有64×36pt唤回按钮，移动鼠标/按键仅恢复控制层。减少动态效果时取消动画。
- 暂停、错误、设置、频道菜单、字幕侧栏、底部悬停、控件键盘焦点或菜单跟踪期间保持展开。顶部与原有全屏、小窗能力保持不变。
- 字幕主按钮切换右侧回看栏，相邻附属菜单明确提供开启／关闭字幕与语言选项。关闭侧栏不关闭识别。
- 回看栏为340pt宽系统材料覆盖层，顶距56pt、底距60pt；继承12pt边距、8pt行间距、13pt正文、11pt时间辅助色、16pt内边距。视频尺寸不随开关改变。最小760pt窗口仍保留至少396pt无遮挡宽度。
- 记录旧到新，最多120条；支持时间、原文、译文、文字选择、导出、关闭、回到最新。跟随时更新滚到底部；开始拖动/滚动即停止自动跟随，按首条可见记录的稳定 ID 锚定阅读位置，同 ID 原文和迟到译文持续更新。记录按120条上限淘汰，若阅读锚点已被淘汰则定位到仍保留的最早记录并提示清理。每条显示来源，切台后不会把不同来源误认为同一记录。“有字幕更新 · 回到最新”恢复跟随；关闭再打开保留阅读状态，切台不强制滚到底部。
- 字幕侧栏不自动收起；空态说明开启字幕产生记录，按钮提供明确帮助和无障碍标签。此次按用户要求不进行真实播放测试，实际播放视觉与时序效果不作为已验证结果。

## 发布样式优先级（2026-09-20 用户确认）
所有本次发布的 App 统一原生 Liquid Glass；新增字幕回看侧栏使用系统 glassEffect，底栏与按钮保持现有 glass/glassProminent，设置采用原生表单。不得退回旧网页外壳或用半透明色块代替液态玻璃。样式优先，保留系统减少透明度和减少动态效果的辅助功能响应。

0% 为不透明底色，100% 为完全透明。隐藏字幕不会停止识别；主界面的「关闭字幕」会停止处理。

翻译服务

只读取当前视频音轨，不使用麦克风或录制其他应用声音。语音识别始终在 Mac 上完成。选择云翻译时，仅发送英文文字；原始音频不上传。

如何添加 Google GCP API
  1. 在 Google Cloud 控制台选择项目并配置结算。
  2. 启用 Cloud Translation API，在「API 和服务 → 凭据」创建 API Key。
  3. 将密钥的 API 限制设为 Cloud Translation API。本 App 由本机服务调用，不使用网页 HTTP Referer 限制。
  4. 粘贴密钥并保存，然后关闭设置、开启字幕。

使用 Basic v2 文本翻译接口，不是 Gemini Key。上下文修订会重复提交增长中的句子，计费用量会高于最终字幕字数。官方接入说明

如何添加火山 API
  1. 在 火山引擎控制台开通「机器翻译」并确认额度。
  2. 在 访问控制 → 密钥管理创建有机器翻译权限的 AK/SK。
  3. 分别粘贴 Access Key ID、Secret Access Key 并保存。
  4. 选择火山服务后开启字幕。这里使用机器翻译 TranslateText 接口，不是豆包／方舟 API Key。

云端调用按火山规则计费；密钥不写入磁盘，退出 App 即清除。官方机器翻译文档

App 不内置模型，首次开启字幕时联网下载；下载后保存在本机，之后重复使用。机器字幕可能误识别人名和数字，中文将结合当前整句更新、句末校正。云服务需要你自己的密钥。
